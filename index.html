Quick start

Dari nol sampai bisa generate dalam satu perintah.

Syarat: Python 3.9 atau lebih baru, koneksi internet untuk instalasi awal dan unduhan model, serta ruang disk sekitar 10 GB untuk venv dan model pertama. GPU itu opsional, CPU tetap bisa generate walau lebih lambat.

Windows PowerShell
irm https://raw.githubusercontent.com/Gaz20KKK/Tunnela/master/tunnela.py -OutFile tunnela.py; python tunnela.py
macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Gaz20KKK/Tunnela/master/tunnela.py -o tunnela.py && python3 tunnela.py
Google Colab / Kaggle notebook
!curl -fsSL https://raw.githubusercontent.com/Gaz20KKK/Tunnela/master/tunnela.py -o tunnela.py && python3 tunnela.py

Apa yang dikerjakan skrip secara berurutan:

  1. Mendeteksi hardware: GPU NVIDIA, Apple Silicon MPS, atau CPU.
  2. Membuat virtualenv .venv supaya proyek tidak mencemari sistem.
  3. Menginstal PyTorch sesuai akselerator, lalu stack diffusers.
  4. Menanyakan link model, kemudian mengunduhnya dengan progress.
  5. Memuat model ke GPU. Kalau VRAM pas-pasan, CPU offload aktif otomatis.
  6. Menyalakan server API di port 7860 dan tunnel Cloudflare, lalu mencetak link trycloudflare.com.

Tekan Ctrl+C untuk mematikan model, server, dan tunnel sekaligus. Jalankan lagi kapan saja dengan python tunnela.py --model LINK, atau --update untuk memperbarui skrip.

Menyiapkan model

Format link apa saja yang diterima skrip.

Saat diminta, tempel salah satu format berikut:

  • Repo diffusers HuggingFace: stabilityai/sd-turbo atau alamat halamannya.
  • File tunggal dari repo: link blob/main/xxx.safetensors.
  • Civitai: buka halaman model, klik tombol Download kanan atas, salin alamatnya yang berformat civitai.com/api/download/models/NOMOR.

Belum punya model? Tekan Enter dan pilih salah satu preset bawaan:

  • Ringan, sd-turbo: sekitar 2,5 GB, langkah 1 sampai 4, masih nyaman di CPU.
  • Seimbang, sdxl-turbo fp16: sekitar 6,9 GB, langkah 4 di resolusi 1024, enak mulai dari GPU 8 GB.
  • Terbaik, FLUX.1-schnell: sekitar 23,8 GB, lisensi Apache 2.0, kualitas paling tinggi tapi berat; GPU besar atau offload panjang.

Keluarga turbo dan schnell dirancang untuk langkah sedikit dengan CFG rendah (1 atau 0). Notebook Colab dan Kaggle otomatis memakai environment bawaan tanpa membuat venv, jadi torch yang sudah terinstal tidak diunduh ulang.

Checkpoint single-file dipetakan otomatis. Nama atau base model yang mengandung XL, Illustrious, atau Pony pakai arsitektur SDXL. Selebihnya default Stable Diffusion. Skrip bertanya kalau ragu.

Model yang sudah diunduh tersimpan di folder models/. Jalankan skrip lagi dan tekan Enter untuk memakainya tanpa mengunduh ulang.

Token akses

Kapan token dibutuhkan dan bagaimana amannya.

  • HuggingFace: repo gated minta access token scope Read dari huggingface.co/settings/tokens. Variabel lingkungan HF_TOKEN juga dibaca.
  • Civitai: API key dari civitai.com/user/account. Unduhan via API saat ini umumnya wajib key meski filenya publik.

Skrip meminta token hanya saat ditolak 401 atau 403. Input memakai getpass sehingga tidak tampil di layar dan tidak masuk riwayat shell. Token hanya hidup selama proses berjalan dan tidak pernah ditulis ke disk.

Hubungkan ke UI

Paste link, uji, generate.

  1. Buka halaman Connect, tempel link trycloudflare dari terminal.
  2. Tekan Uji koneksi. Bila sukses lanjut ke Workspace.
  3. Tulis prompt, atur parameter kalau perlu, Generate.

Sebelum backend terhubung, Workspace jalan dalam mode demo dengan gambar placeholder agar kamu bisa mencoba antarmuka. Shortcut Ctrl Enter juga berfungsi.

Troubleshooting

Masalah yang paling sering muncul.

Buat access token scope Read di huggingface.co/settings/tokens lalu tempel saat skrip bertanya. Setelah itu cukup jalankan lagi perintah yang sama.
Turunkan resolusi atau batch. Skrip sudah memakai CPU offload otomatis kalau free VRAM tidak cukup, tapi resolusi 1024 dengan batch besar tetap bisa melebihi kapasitas.
Masukkan API key dari civitai.com/user/account saat diminta. Key gratis untuk semua akun.
Pastikan internet keluar bebas dan firewall tidak memblokir cloudflared. Cloudflare memberlakukan rate limit pada quick tunnel, tunggu beberapa menit lalu jalankan lagi.
Wajar. Warm-up dan kompilasi kernel hanya terjadi sekali di awal. Pada murni CPU, resolusi rendah dengan langkah sedikit adalah titik mulai yang baik.
